# Function for reading chromosomes from a \`.cool\` or \`.mcool\` file

Function for reading chromosomes from a \`.cool\` or \`.mcool\` file

## Usage

``` r
readCoolChroms(fname, resolution)
```

## Arguments

- fname:

  path to .cool or .mcool file

- resolution:

  for .mcool files,

## Value

Data frame of chromosome names and lengths
